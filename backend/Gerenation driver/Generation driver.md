# Generation Driver - сервис по генерации потока стоимостей котировок
## Тип компонента:   
драйвер устройства (Linux Kernel Module)
## Написан на C
## Использует [[Driver config]], системный энтропийный движок ядра
## Используется в [[Quotation publisher]]

## Описание функционала

Драйвер представляет собой низкоуровневый генератор рыночных данных. Он имитирует волатильность цен на уровне ядра Linux. 

Ключевые возможности:
- **Символьное устройство**: создает файл устройства `/dev/price_feed` с правами доступа `0666`.
- **Конфигурируемость**: параметры цен (тикер, начальная цена, верхний и нижний лимиты) считываются из CSV-файла `/etc/price_driver/config.csv` при инициализации.
- **Алгоритм волатильности**: реализует модель случайного блуждания. Новая цена вычисляется на основе текущей плюс случайная дельта, не выходя за установленные границы.
- **Бинарный протокол**: отдает данные в компактном виде (12 байт на запись).

## Технические характеристики

- **Интерфейс доступа**: стандартные файловые операции (`open`, `read`, `release`).
- **Формат вывода**:
  - Байты `0–7`: Тикер акции (null-padded string).
  - Байты `8–11`: Цена (`uint32_t`).
- **Runtime-настройка**: поддерживает изменение параметров (таймаут генерации, процент дельты) "на лету" через файлы в `/sys/module/price_driver/parameters/`.

## Параметры модуля

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| `config_path` | `/etc/price_driver/config.csv` | Путь к CSV-файлу с тикерами |
| `max_delta_percent` | `5` | Макс. изменение цены за один шаг (%) |
| `generation_timeout_ms` | `100` | Задержка между циклами генерации |
| `buffer_size` | `4096` | Размер внутреннего буфера ядра |

## Взаимодействие в системе

1. **Запуск**: при загрузке (`insmod`) считывает [[Driver config|config.csv]].
2. **Генерация**: по запросу `read()` вычисляет новые цены для всех тикеров в списке.
3. **Передача**: использует `copy_to_user` для безопасной передачи бинарного пакета в [[Quotation publisher]].
4. **Безопасность**: использует `mutex` для предотвращения состояния гонки (race condition) при одновременном доступе и обновлении цен.

## Файловая структура

- `price_driver.c` — основной код драйвера.
- `config.h` — макросы и параметры по умолчанию.
- `Makefile` — сценарий сборки модуля.
- `99-price_feed.rules` — правила автоматической настройки прав доступа в Linux.
