# конфигурационный файл котировок
## Тип компонента:   
CSV-файл конфигурации (Plain Text)
## Формат данных:
разделитель запятая (`,`), без заголовков (headerless), кодировка ASCII/UTF-8
## Используется в [[Generation Driver]]

## Описание функционала

Файл служит источником первичных данных для инициализации драйвера генерации цен. Он определяет список отслеживаемых тикеров, их допустимые ценовые границы и стартовое значение. Драйвер парсит файл единожды при загрузке модуля, формируя внутреннюю структуру `ticker_config`, которая далее используется алгоритмом случайного блуждания.

Ключевые особенности:
- **Простота редактирования**: текстовый формат, легко изменяется через любой редактор или скрипт.
- **Комментарии и пробелы**: строки, начинающиеся с `#`, игнорируются. Ведущие пробелы у токенов автоматически обрезаются парсером.
- **Целочисленное представление**: цены задаются в формате `long` (обычно цена × 100 или в условных пунктах), что исключает ошибки плавающей запятой в пространстве ядра.

## Технические характеристики

- **Максимальный размер файла**: `65 536` байт (64 КБ). При превышении драйвер отклоняет загрузку с ошибкой `-EINVAL`.
- **Максимальное количество записей**: ограничено константой `max_tickers` в `config.h`.
- **Лимит длины строки**: ограничено `MAX_LINE_LEN` (защита от переполнения буфера при чтении).
- **Безопасность**: парсинг происходит в изолированном буфере (`kmalloc`), после успешной загрузки данные атомарно передаются в основную структуру под защитой `mutex`.
- **Типы данных**: 
  - Поле 0: строка (`char[]`, до `ticker_len` символов)
  - Поля 1–3: целые числа со знаком (`long`)

## Параметры записи

| Колонка | Пример | Описание |
|---------|--------|----------|
| `0` | `AAPL` | Тикер актива. Копируется в структуру драйвера, дополняется `\0`. |
| `1` | `18000` | Верхний лимит цены (`upper_bound`). Граница для алгоритма волатильности. |
| `2` | `16000` | Нижний лимит цены (`lower_bound`). Граница для алгоритма волатильности. |
| `3` | `17050` | Начальная/текущая цена (`current_price`). От неё отсчитывается первое случайное блуждание. |

## Взаимодействие в системе

1. **Загрузка**: при вызове `insmod` драйвер обращается к файлу по пути, указанному в параметре `config_path` (по умолчанию `/etc/price_driver/config.csv`).
2. **Чтение ядра**: файл открывается через `filp_open`, содержимое считывается `kernel_read` в выделенный буфер.
3. **Парсинг**: строки разделяются по `\n`, затем токены разбираются `strsep` по `,`. Каждое числовое значение конвертируется `kstrtol`.
4. **Валидация**: строка принимается только если содержит ровно `4` поля. При успехе данные логируются в `dmesg`: `Loaded AAPL [16000-18000] initial=17050`.
5. **Применение**: после парсинга всех валидных строк указатель на массив тикеров атомарно обновляется в `ticker_config`. Динамическое обновление файла во время работы драйвера **не поддерживается** (требуется `rmmod` / `insmod`).

## Файловая структура

- **Расположение по умолчанию**: `/etc/price_driver/config.csv`
- **Права доступа**: рекомендуется `0644` (чтение для всех, запись только для `root`)
- **Пример содержимого**:
  ```csv
  # Основные технологические тикеры
  AAPL,18000,16000,17050
  GOOGL,14000,12000,13230
  MSFT,38000,36000,37520
  TSLA,25000,20000,22580
  AMZN,17000,15000,16240
  ```
- **Связанные компоненты**: 
  - `config.h` — содержит дефолтные пути и лимиты (`max_tickers`, `max_line_len`, `ticker_len`)
  - `99-price_feed.rules` — udev-правило, обеспечивающее доступ к `/dev/price_feed` для пользователей
