# Обзор проекта Stocky

**Stocky** — это современное Android-приложение для мониторинга фондового рынка и управления инвестиционным портфелем. Приложение позволяет пользователям отслеживать цены акций в реальном времени, просматривать графики и совершать имитационные торговые операции.

## Основной функционал
- **Авторизация:** Система входа и регистрации пользователей.
- **Рынок:** Список доступных акций с обновлением цен в реальном времени.
- **Графики:** Визуализация истории цен в виде японских свечей.
- **Портфель:** Управление активами, расчет общей стоимости и прибыли/убытков.
- **Профиль:** Персональная статистика инвестора.

## Стек технологий
- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material3)
- **Архитектура:** MVVM (Model-View-ViewModel)
- **Сеть:** Ktor (HTTP + WebSockets)
- **Сериализация:** kotlinx.serialization
- **Асинхронность:** Kotlin Coroutines & Flow
