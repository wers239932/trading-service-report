# Пользовательский интерфейс (UI)

Интерфейс полностью написан на **Jetpack Compose**.

## Основные компоненты
- **BrokerAppContent:** Центральный роутер, переключающий экраны в зависимости от `isLoggedIn`.
- **MainTabs:** Нижняя навигация (Рынок, Портфель, Профиль).
- **ModernStockCard:** Раскрывающаяся карточка акции с графиком и кнопками действий.
- **CandlestickChart:** Кастомный компонент на `Canvas` для отрисовки японских свечей.

## Темизация
Приложение поддерживает светлую и тёмную темы. Цвета определены в `ui/theme/Color.kt`, а логика переключения в `Theme.kt`.

### Пример структуры экрана
```kotlin
@Composable
fun MarketScreen(...) {
    LazyColumn {
        item { /* Карточка общего баланса */ }
        items(stocks) { stock ->
            ModernStockCard(stock, ...)
        }
    }
}
```
